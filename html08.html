Parâmetros:

  • action: necessário para todo form. Seu valor é a url da página do servidor que receberá os dados;
  • method: formulários podem ser enviados com os métodos get e post;
  • type: o tipo do campo. Pode ser text, password, number etc.
  • name: é o nome do campo
  • id: é o identificador do campo
  • value: pode definir o valor enviado ao servidor quando o formulário é submetido ou inicializar um campo com um valor;
  • maxlength e minlength: tamanho máximo e mínimo de um campo de texto;
  • checked: indica se um campo já pode iniciar sendo selecionado em um formulario de radio ou checkbox;
  • selected: para já aparecer com a opção selecionada ao carregar a página;
  • selected disabled: quando não quer que nenhuma opção seja marcada no menu de caixa suspensa;
  • multiple: para selecionar mais de uma opção de uma caixa de múltipla seleção;
  • size: atributo que altera o tamanho do campo (não usar com inputs, ele é reservado pra elementos de formulários mais antigos);
  • max e min: tamanho máximo e mínimo de um campo numérico;
  • for: para associar um label a um input pelo id;
  • fieldset: agrupar controles de formulários relacionados;
  • legend: é uma legenda que vêm imediatamente após o fieldset;
  • required: quando o preenchimento é obrigatório;
  • placeholder: para o campo ser carregado com alguma instrução de preenchimento;
  • accept: para limitar, no campo de upload, quais tipos de arquivos podem ser enviados.
